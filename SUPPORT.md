# Getting support

Agorail Labs hosts experimental open-source research projects, not a hosted payment processor, billing service, or production support offering.

## Choose the correct project

| Question | Where to go |
| --- | --- |
| Subscription changes, quote/commit/reconcile, billing-adapter evidence | [SCQ repository](https://github.com/agorail-labs/subscription-change-quote) |
| General commercial mutation safety, admission constraints, multi-unit outcomes | [MSE repository](https://github.com/agorail-labs/mutation-safety-envelope) |
| Scope or relationship between projects | [PROJECTS.md](PROJECTS.md) |

For reproducible defects or documentation corrections, open an **Issue** in the relevant repository after checking existing reports. Include the affected version, minimal steps, expected outcome, actual outcome, and supporting evidence.

For exploratory design questions, use **Discussions where enabled**. General questions do not establish an integration commitment or maintenance service.

For security-sensitive issues, use the private path in [SECURITY.md](SECURITY.md), **not** public Issues or Discussions.

No response-time SLA, guaranteed maintenance window, or production support is implied. For help using a billing or payment provider's commercial API, consult that provider's own official documentation and support channel.
